# Maqueen Step Line

บล็อก MakeCode สำหรับ DFRobot Maqueen ของน้องดิน ใช้เดินตามเส้นดำบนพื้นขาว และนับ "ก้าว" จากจุดตัดของเส้นดำ

## รูปแบบสนาม

- พื้นสนามเป็นสีขาว
- เส้นทางหลักใช้เทปพันสายไฟสีดำ
- checkpoint คือเส้นเทปสีดำอีกเส้นที่ตัดผ่านเส้นทางหลัก
- เมื่อตัวรถผ่านจุดตัด เซนเซอร์ซ้ายและขวาจะเจอสีดำพร้อมกัน จึงนับเป็น 1 ก้าว

## บล็อกที่เพิ่ม

- `เดินตามเส้นดำไปข้างหน้า N ก้าว (จุดตัด) ความเร็ว S ความเร็วเลี้ยว T`
- `เจอจุดตัดเส้นดำ`
- `เดินตามเส้นดำ ความเร็ว S ความเร็วเลี้ยว T`
- `รถวิ่ง เดินหน้า/ถอยหลัง เป็นเวลา T วินาที ความเร็ว S`
- `เลี้ยว ซ้าย/ขวา 90 องศา/180 องศา ความเร็ว S`
- `ตั้งเวลาเลี้ยว 90 องศาเป็น T ms`
- `หยุดรถ Maqueen`
- `ค่า analog เซนเซอร์เส้น ซ้าย/ขวา`
- `เซนเซอร์เส้น ซ้าย/ขวา เจอสีดำ`
- `ตำแหน่งเส้น`
- `มอเตอร์ ซ้าย/ขวา/ทั้งสอง วิ่ง เดินหน้า/ถอยหลัง ความเร็ว S`
- `หยุดมอเตอร์ ซ้าย/ขวา/ทั้งสอง`
- `ตั้งค่าเซนเซอร์อ่านสีดำเป็น 0/1`

## วิธีนับก้าว

ใช้บล็อก `เดินตามเส้นดำไปข้างหน้า N ก้าว (จุดตัด) ความเร็ว S ความเร็วเลี้ยว T`

ตัวอย่าง:

1. วางรถบนเส้นดำหลัก
2. ใช้บล็อก `เดินตามเส้นดำไปข้างหน้า 2 ก้าว (จุดตัด) ความเร็ว 80 ความเร็วเลี้ยว 45`
3. รถจะเดินตามเส้นดำ
4. เมื่อผ่านจุดตัดเส้นดำ 2 ครั้ง รถจะหยุด

ถ้าเซนเซอร์ของคุณอ่านสีดำเป็น `1` แทน `0` ให้ใช้บล็อก `ตั้งค่าเซนเซอร์อ่านสีดำเป็น 1` ตอนเริ่มโปรแกรม

## การเลี้ยว 90 และ 180 องศา

บล็อก `เลี้ยว ซ้าย/ขวา 90 องศา/180 องศา ความเร็ว S` จะหมุนล้อซ้ายและขวาสวนทางกัน
ค่าเริ่มต้นของเวลาเลี้ยว 90 องศาคือ `420 ms`

ถ้ารถเลี้ยวน้อยหรือมากเกินไป ให้ปรับด้วยบล็อก `ตั้งเวลาเลี้ยว 90 องศาเป็น T ms`
เช่น ถ้าเลี้ยว 90 องศาแล้วยังไม่ถึงมุม ให้เพิ่มค่าเป็น `450` หรือ `500`

## การเดินแบบไม่ตามเส้น

ใช้บล็อก `รถวิ่ง เดินหน้า/ถอยหลัง เป็นเวลา T วินาที ความเร็ว S`
บล็อกนี้จะสั่งให้ล้อทั้งสองข้างวิ่งตามเวลาที่กำหนด แล้วหยุดเอง

ตัวอย่าง:

1. `รถวิ่ง เดินหน้า เป็นเวลา 2 วินาที ความเร็ว 80`
2. `เลี้ยว ซ้าย 90 องศา ความเร็ว 70`
3. `รถวิ่ง ถอยหลัง เป็นเวลา 3 วินาที ความเร็ว 80`
