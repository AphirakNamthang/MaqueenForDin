# Maqueen Step Line

บล็อก MakeCode สำหรับ DFRobot Maqueen ของน้องดิน ใช้เดินตามเส้นดำบนพื้นขาว และนับ "ก้าว" จากจุดตัดของเส้นดำ

## รูปแบบสนาม

- พื้นสนามเป็นสีขาว
- เส้นทางหลักใช้เทปพันสายไฟสีดำ
- checkpoint คือเส้นเทปสีดำอีกเส้นที่ตัดผ่านเส้นทางหลัก
- เมื่อตัวรถผ่านจุดตัด เซนเซอร์ซ้ายและขวาจะเจอสีดำพร้อมกัน จึงนับเป็น 1 ก้าว

## เลี้ยวกับหมุนต่างกันอย่างไร

`เลี้ยว` คือมอเตอร์ข้างหนึ่งหยุด อีกข้างหนึ่งหมุนเดินหน้า รถจะเลี้ยวเป็นวงกว้างกว่า

ตัวอย่างเลี้ยวซ้าย:

- มอเตอร์ซ้ายหยุด
- มอเตอร์ขวาเดินหน้า

`หมุน` คือมอเตอร์ซ้ายและขวาหมุนสวนทางกัน รถจะหมุนอยู่กับที่

ตัวอย่างหมุนซ้าย:

- มอเตอร์ซ้ายถอยหลัง
- มอเตอร์ขวาเดินหน้า

## วิธีนับก้าว

ใช้บล็อก `เดินตามเส้นดำไปข้างหน้า N ก้าว (จุดตัด) ความเร็ว S ความเร็วเลี้ยว T`

ตัวอย่าง:

1. วางรถบนเส้นดำหลัก
2. ใช้บล็อก `เดินตามเส้นดำไปข้างหน้า 2 ก้าว (จุดตัด) ความเร็ว 80 ความเร็วเลี้ยว 45`
3. รถจะเดินตามเส้นดำ
4. เมื่อผ่านจุดตัดเส้นดำ 2 ครั้ง รถจะหยุด

ถ้าเซนเซอร์ของคุณอ่านสีดำเป็น `1` แทน `0` ให้ใช้บล็อก `ตั้งค่าเซนเซอร์อ่านสีดำเป็น 1` ตอนเริ่มโปรแกรม

## หาเส้นเมื่อหลุดเส้น

ถ้ารถไม่เจอเส้นเลย เซนเซอร์ซ้ายและขวาเห็นพื้นขาวพร้อมกัน รถจะหมุนหาเส้นช้า ๆ
ค่าเริ่มต้นคือหมุนซ้ายที่ความเร็ว `35`
ปรับได้ด้วยบล็อก `ตั้งค่าหาเส้น หมุน ซ้าย/ขวา ความเร็ว S`

ถ้าต้องการเขียนเงื่อนไขเอง ให้ใช้แบบนี้:

1. `if ไม่เจอเส้นดำเลย`
2. ใส่บล็อก `หมุนหาเส้น`
3. `else`
4. ใส่บล็อก `เดินตามเส้นดำ ความเร็ว 80 ความเร็วเลี้ยว 45`

## การเลี้ยวแบบจับเส้น

บล็อก `เลี้ยว ซ้าย/ขวา 90 องศา/180 องศา ความเร็ว S` จะเลี้ยวโดยให้มอเตอร์ข้างหนึ่งหยุด อีกข้างเดินหน้า แล้วใช้ line sensor หาเส้นดำ

หลักการ:

1. เริ่มเลี้ยวซ้ายหรือขวาตามที่เลือก
2. หน่วงเวลาเริ่มต้น `200 ms` เพื่อให้เซนเซอร์พ้นจากเส้นหลักเดิม
3. ถ้าเลือก `90 องศา` รถจะเลี้ยวจนเซนเซอร์ด้านที่เลี้ยวเจอเส้นดำครั้งแรก แล้วหยุด
4. ถ้าเลือก `180 องศา` รถจะเลี้ยวจนเซนเซอร์ด้านที่เลี้ยวเจอเส้นดำครั้งที่สอง แล้วหยุด

ถ้าเซนเซอร์ยังเจอเส้นเดิมตอนเริ่มเลี้ยว ให้เพิ่มบล็อก `ตั้งเวลาหน่วงก่อนหาเส้นตอนเลี้ยวเป็น T วินาที`
ถ้ารถเลี้ยวแล้วหาเส้นไม่เจอ ระบบจะหยุดเมื่อครบเวลาสูงสุด ค่าเริ่มต้นคือ `3 วินาที`

## การเลี้ยวและหมุนแบบเวลา

ถ้าต้องการเลี้ยวโดยไม่อ้างอิงเส้นดำ ให้ใช้บล็อกกลุ่มเวลา

- ใช้ `เลี้ยวแบบเวลา ...` เมื่อต้องการให้ล้อข้างหนึ่งหยุด อีกข้างเดินหน้า
- ใช้ `หมุนแบบเวลา ...` เมื่อต้องการให้ล้อซ้ายและขวาหมุนสวนทางกัน

## การเดินแบบไม่ตามเส้น

ใช้บล็อก `รถวิ่ง เดินหน้า/ถอยหลัง เป็นเวลา T วินาที ความเร็ว S`
บล็อกนี้จะสั่งให้ล้อทั้งสองข้างวิ่งตามเวลาที่กำหนด แล้วหยุดเอง

ตัวอย่าง:

1. `รถวิ่ง เดินหน้า เป็นเวลา 2 วินาที ความเร็ว 80`
2. `เลี้ยวแบบเวลา ซ้าย เป็นเวลา 1 วินาที ความเร็ว 70`
3. `รถวิ่ง ถอยหลัง เป็นเวลา 3 วินาที ความเร็ว 80`
