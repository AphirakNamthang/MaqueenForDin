# Maqueen Step Line

บล็อก MakeCode สำหรับ DFRobot Maqueen ของน้องดิน ใช้เดินตามเส้นดำบนพื้นขาว และนับ "ก้าว" จากจุดตัดของเส้นดำ

## รูปแบบสนาม

- พื้นสนามเป็นสีขาว
- เส้นทางหลักใช้เทปพันสายไฟสีดำ
- checkpoint คือเส้นเทปสีดำอีกเส้นที่ตัดผ่านเส้นทางหลัก
- เมื่อตัวรถผ่านจุดตัด เซนเซอร์ซ้ายและขวาจะเจอสีดำพร้อมกัน จึงนับเป็น 1 ก้าว

## วิธีนับก้าว

ใช้บล็อก `เดินตามเส้นดำไปข้างหน้า N ก้าว (จุดตัด) ความเร็ว S ความเร็วเลี้ยว T`

ตัวอย่าง:

1. วางรถบนเส้นดำหลัก
2. ใช้บล็อก `เดินตามเส้นดำไปข้างหน้า 2 ก้าว (จุดตัด) ความเร็ว 80 ความเร็วเลี้ยว 45`
3. รถจะเดินตามเส้นดำ
4. เมื่อผ่านจุดตัดเส้นดำ 2 ครั้ง รถจะหยุด

ถ้าเซนเซอร์ของคุณอ่านสีดำเป็น `1` แทน `0` ให้ใช้บล็อก `ตั้งค่าเซนเซอร์อ่านสีดำเป็น 1` ตอนเริ่มโปรแกรม

ถ้ารถไม่เจอเส้นเลย เซนเซอร์ซ้ายและขวาเห็นพื้นขาวพร้อมกัน รถจะหมุนหาเส้นช้า ๆ
ค่าเริ่มต้นคือหมุนซ้ายที่ความเร็ว `35`
ปรับได้ด้วยบล็อก `ตั้งค่าหาเส้น หมุน ซ้าย/ขวา ความเร็ว S`

ถ้าต้องการเขียนเงื่อนไขเอง ให้ใช้แบบนี้:

1. `if ไม่เจอเส้นดำเลย`
2. ใส่บล็อก `หมุนหาเส้น`
3. `else`
4. ใส่บล็อก `เดินตามเส้นดำ ความเร็ว 80 ความเร็วเลี้ยว 45`

## การเลี้ยว 90 และ 180 องศา

บล็อก `เลี้ยว ซ้าย/ขวา 90 องศา/180 องศา ความเร็ว S` จะหมุนล้อซ้ายและขวาสวนทางกัน แล้วใช้ line sensor หาเส้นดำ

หลักการ:

1. เริ่มหมุนซ้ายหรือขวาตามที่เลือก
2. หน่วงเวลาเริ่มต้น `200 ms` เพื่อให้เซนเซอร์พ้นจากเส้นหลักเดิม
3. ถ้าเลือก `90 องศา` รถจะหมุนจนเซนเซอร์ด้านที่เลี้ยวเจอเส้นดำครั้งแรก แล้วหยุด
4. ถ้าเลือก `180 องศา` รถจะหมุนจนเซนเซอร์ด้านที่เลี้ยวเจอเส้นดำครั้งที่สอง แล้วหยุด

ถ้าเซนเซอร์ยังเจอเส้นเดิมตอนเริ่มเลี้ยว ให้เพิ่มบล็อก `ตั้งเวลาหน่วงก่อนหาเส้นตอนเลี้ยวเป็น T ms`
ถ้ารถหมุนแล้วหาเส้นไม่เจอ ระบบจะหยุดเมื่อครบเวลาสูงสุด ค่าเริ่มต้นคือ `3000 ms`

ถ้าต้องการเลี้ยวโดยไม่อ้างอิงเส้นดำ ให้ใช้บล็อก `หมุน ซ้าย/ขวา เป็นเวลา T ms ความเร็ว S`
หรือ `หมุนตามเวลา ซ้าย/ขวา 90 องศา/180 องศา ความเร็ว S เวลา 90 องศา T ms`
บล็อกกลุ่มนี้ใช้เวลาอย่างเดียว ไม่อ่าน line sensor

## การเดินแบบไม่ตามเส้น

ใช้บล็อก `รถวิ่ง เดินหน้า/ถอยหลัง เป็นเวลา T วินาที ความเร็ว S`
บล็อกนี้จะสั่งให้ล้อทั้งสองข้างวิ่งตามเวลาที่กำหนด แล้วหยุดเอง

ตัวอย่าง:

1. `รถวิ่ง เดินหน้า เป็นเวลา 2 วินาที ความเร็ว 80`
2. `เลี้ยว ซ้าย 90 องศา ความเร็ว 70`
3. `รถวิ่ง ถอยหลัง เป็นเวลา 3 วินาที ความเร็ว 80`
