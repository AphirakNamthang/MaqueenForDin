# Maqueen Step Line

บล็อก MakeCode สำหรับ DFRobot Maqueen ของน้องดิน ใช้กับ Maqueen Robot V4

## สนาม

- พื้นสีขาว
- เส้นหลักเป็นเทปสีดำ
- จุดตัดสีดำคือ checkpoint
- สีดำถูก fix เป็นค่าเซนเซอร์ `0`

## บล็อกหลัก

- `เดินตามเส้นดำไปข้างหน้า N ก้าว (จุดตัด) ความเร็ว S ความเร็วเลี้ยว T`
- `เดินตามเส้นดำ ความเร็ว S ความเร็วเลี้ยว T`
- `เลี้ยว ซ้าย/ขวา 90 องศา/180 องศา`
- `หมุน ซ้าย/ขวา 90 องศา/180 องศา`
- `หมุน ซ้าย/ขวา เป็นเวลา T วินาที ความเร็ว S`
- `เลี้ยวแบบเวลา ซ้าย/ขวา เป็นเวลา T วินาที ความเร็ว S`
- `รถวิ่ง เดินหน้า/ถอยหลัง เป็นเวลา T วินาที ความเร็ว S`
- `หยุดรถ Maqueen`
- `ระยะ Ultrasonic (เซนติเมตร)`
- `เจอวัตถุข้างหน้า`
- `ชนวัตถุเลี้ยว ซ้าย/ขวา X ครั้ง ความเร็วเดินหน้า S`
- `ชนวัตถุหมุน ซ้าย/ขวา X ครั้ง ความเร็วเดินหน้า S`

## ตั้งค่า

- `ตั้งค่าความเร็วเลี้ยวเป็น S`
- `ตั้งเวลาหน่วงก่อนหาเส้นตอนเลี้ยวเป็น T วินาที`
- `ตั้งเวลาหาเส้นตอนเลี้ยวสูงสุด T วินาที`
- `ตั้งค่าความเร็วหมุนเป็น S`
- `ตั้งเวลา 90 องศาตอนหมุนเป็น T วินาที`
- `มอเตอร์ ซ้าย/ขวา วิ่งเร็วขึ้น P เปอร์เซ็นต์`
- `ตั้งค่าหาเส้น หมุน ซ้าย/ขวา ความเร็ว S`
- `ตั้งเวลา debounce จุดตัดเป็น T ms`
- `ตั้งค่าระยะชนวัตถุเป็น D เซนติเมตร`

## ความหมายของเลี้ยวและหมุน

`เลี้ยว` คือมอเตอร์ข้างหนึ่งหยุด อีกข้างหนึ่งหมุนเดินหน้า

`หมุน` คือมอเตอร์ซ้ายและขวาหมุนสวนทางกัน

## จูนมอเตอร์ซ้าย/ขวา

ถ้ารถวิ่งแล้วเอียง ให้ใช้บล็อก `มอเตอร์ ซ้าย/ขวา วิ่งเร็วขึ้น P เปอร์เซ็นต์`

ตัวอย่าง:

- ตั้ง `มอเตอร์ ซ้าย วิ่งเร็วขึ้น 10 เปอร์เซ็นต์`
- ถ้าสั่งวิ่งความเร็ว `100`
- มอเตอร์ซ้ายจะวิ่งที่ `110`
- มอเตอร์ขวายังวิ่งที่ `100`
